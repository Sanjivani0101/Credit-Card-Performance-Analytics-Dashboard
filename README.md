# Credit-Card-Performance-Analytics-Dashboard
Credit Card Performance Analytics Dashboard built in Power BI, providing executive-level insights into transactions, revenue trends, and customer behavior through interactive and well-structured reports.

Objective - Analyze credit card transaction and customer data using Power BI to uncover key revenue drivers and customer behavior insights.

Executive Overview - High-level insights and key takeaways with guided navigation.

Transaction Report - Analysis of revenue, interest, transaction trends, and usage channels.

Customer Report - Insights into customer demographics, segments, and spending behavior.
